---

## 1. Goal

Implement accessible (`WCAG 2.2 AA`), keyboard-navigable React components for Nigerian address workflows: `<StateLgaSelect />` for offline administrative selection, `<NigerianAddressInput />` smart combobox with automatic NDAPS detection, `<AddressConfirmationCard />` for inline review, and `<AddressConfirmationModal />` with focus trapping and backdrop dismissal. Deliver a polished default CSS stylesheet (`styles.css`) utilizing CSS custom properties (`--nga-*`) and full reduced-motion support.

---

## 2. Tasks

### Task 1: Cascading State & LGA Selector Component
- Create `packages/react/src/components/StateLgaSelect.tsx`:
  - Utilizes `@ng-address/core`'s `NIGERIAN_STATES` dataset for instant zero-latency offline dropdowns.
  - Cascading logic: Selecting a state automatically updates the available Local Government Areas (LGAs).
  - Semantic `<select>` elements with `<label for="...">`, visible focus styling, and `onChange` callback returning `{ state, stateCode, lga, ward }`.
  - Accessible error and required field attributes (`aria-invalid`, `aria-required`).

### Task 2: Smart Combobox Input (`<NigerianAddressInput />`)
- Create `packages/react/src/components/NigerianAddressInput.tsx`:
  - Smart unified search input that auto-detects NDAPS digital postcodes (e.g., `LA-11-W06-TC-10` or traditional `100001`) vs unstructured text.
  - Inline toggle button to switch between Smart Search and manual `<StateLgaSelect />` hierarchy entry.
  - WAI-ARIA 1.2 Combobox pattern:
    - Input: `role="combobox"`, `aria-expanded`, `aria-autocomplete="list"`, `aria-controls`, `aria-activedescendant`.
    - Dropdown: `role="listbox"`, items: `role="option"`, `aria-selected`.
  - Full keyboard navigation:
    - `ArrowDown` / `ArrowUp` to navigate suggestions listbox without scrolling the page (`e.preventDefault()`).
    - `Enter` to select suggestion without inadvertently submitting enclosing `<form>`.
    - `Escape` to close suggestion listbox.
  - Live region (`role="status"`, `aria-live="polite"`) announcing suggestion counts for screen reader users.

### Task 3: Dual Confirmation Components (Inline Card & Accessible Modal)
- Create `packages/react/src/hooks/useFocusTrap.ts`:
  - Lightweight hook managing `Tab` / `Shift+Tab` focus cycles, `Escape` key close listener, and returning focus to trigger element on unmount.
- Create `packages/react/src/components/AddressConfirmationCard.tsx`:
  - Compact, beautifully structured card displaying normalized address breakdown:
    - Formatted address string
    - State & State Code, LGA, Ward
    - Street & Building metadata
    - NDAPS Postcode with copy action
    - Geographic Coordinates with precision badge
    - Provenance indicators (e.g. `source: "nipost"`, `verified: true`)
  - "Confirm Address" and "Edit" action buttons.
- Create `packages/react/src/components/AddressConfirmationModal.tsx`:
  - Accessible dialog (`role="dialog"`, `aria-modal="true"`, `aria-labelledby`, `aria-describedby`).
  - Renders `<AddressConfirmationCard />` inside focus-trapped portal with backdrop click-to-dismiss and `Escape` handling.

### Task 4: Default CSS Design System (`styles.css`)
- Create `packages/react/src/styles/index.css`:
  - Clean CSS custom variables:
    - Colors: `--nga-bg`, `--nga-surface`, `--nga-border`, `--nga-text`, `--nga-text-muted`, `--nga-primary`, `--nga-ring`
    - Typography & Radius: `--nga-radius`, `--nga-font`, `--nga-shadow`
  - High-contrast `:focus-visible` ring (2px solid, >=4.5:1 contrast).
  - Micro-interactions: `scale(0.96)` button click feedback, smooth opacity transitions.
  - `@media (prefers-reduced-motion: reduce)` rules overriding animations to instant state changes.
  - Minimum touch targets (44x44px mobile, 40x40px desktop hit targets).

### Task 5: Component & Accessibility Test Suite
- Create `packages/react/test/input.test.tsx`:
  - Test smart postcode auto-detection and suggestion rendering.
  - Test toggle switching between search and `<StateLgaSelect />`.
- Create `packages/react/test/cascade.test.tsx`:
  - Test State selection dynamically populating the corresponding LGA dropdown options.
- Create `packages/react/test/modal.test.tsx`:
  - Test modal opening, focus trapping, Escape key closing, and backdrop dismissal.
- Create `packages/react/test/a11y.test.tsx` & `packages/react/test/keyboard.test.tsx`:
  - Test ARIA attributes on combobox, listbox, and dialog.
  - Test keyboard navigation: ArrowUp/Down, Enter selection, Escape close, and Tab focus cycling.
