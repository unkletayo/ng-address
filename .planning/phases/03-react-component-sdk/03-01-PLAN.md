# Phase 3 Plan 1: React Package Scaffold, Address Context Provider & Headless Hooks

**Plan:** `03-01`  
**Phase:** `03-react-component-sdk`  
**Target:** `packages/react`  
**Requirements:** `REACT-02`  
**Dependencies:** `@ng-address/core`  
**Threat Ref:** `T-03-01` (Client-side credential isolation and request abort handling)

---

## 1. Goal

Scaffold the `@ng-address/react` package with TypeScript, React 18/19 peer dependencies, and `tsup` build configuration. Implement `<AddressConfigProvider />` for global backend proxy endpoint configuration, along with headless React hooks `useAddressResolution()`, `usePostcodeLookup()`, and `useAddressConfig()` that manage asynchronous query resolution, error mapping, cancellation (`AbortController`), and debouncing.

---

## 2. Tasks

### Task 1: Package Scaffolding & Build Configuration
- Create `packages/react/package.json`:
  - `name`: `@ng-address/react`
  - `peerDependencies`: `react: ">=18.0.0"`, `react-dom: ">=18.0.0"`
  - `dependencies`: `@ng-address/core: "workspace:*"`
  - `devDependencies`: `tsup`, `typescript`, `@testing-library/react`, `@testing-library/user-event`, `jsdom`
  - Build script: `tsup` targeting ESM, CJS, and TypeScript definitions (`.d.ts`).
- Create `packages/react/tsconfig.json` extending `../../tsconfig.base.json` with JSX support (`"jsx": "react-jsx"`).
- Create `packages/react/tsup.config.ts` configured for React entrypoint and CSS bundle injection.

### Task 2: Address Configuration Context & Provider
- Create `packages/react/src/context/AddressConfigContext.tsx`:
  - `AddressConfig` interface:
    - `proxyUrl?: string` (e.g., `"/api/address/resolve"`)
    - `headers?: Record<string, string>`
    - `debounceMs?: number` (default: 300)
    - `resolveAddress?: (query: string | Partial<NigerianAddress>) => Promise<NigerianAddress>`
  - `<AddressConfigProvider value={...}>` context provider.
  - `useAddressConfig()` hook to consume configuration with safe fallback defaults.

### Task 3: Headless Resolution & Postcode Hooks
- Create `packages/react/src/hooks/useAddressResolution.ts`:
  - State machine: `status: 'idle' | 'loading' | 'resolved' | 'error'`.
  - Debounced execution using `setTimeout` or `startTransition`.
  - Automatic `AbortController` cancellation for in-flight requests when query updates or component unmounts.
  - Normalizes results into canonical `NigerianAddress` using `@ng-address/core`.
- Create `packages/react/src/hooks/usePostcodeLookup.ts`:
  - Specialized hook for digital / traditional postcode lookup.
  - Offline format validation using `isValidPostcodeFormat` before network calls.
  - Returns `address`, `status`, `error`, and `lookup(postcode)` trigger.
- Create `packages/react/src/types/index.ts` exporting all hook and context interfaces.
- Create barrel export in `packages/react/src/index.ts`.

### Task 4: Unit Tests for Hooks & Context
- Create `packages/react/test/hooks.test.tsx`:
  - Test `<AddressConfigProvider />` default values and context overrides.
  - Test `useAddressResolution` loading, success, debounce timing, and AbortController cancellation on rapid input.
  - Test `usePostcodeLookup` rejecting invalid postcodes offline and resolving valid postcodes.
  - Test `AddressError` translation to friendly UI error messages.
