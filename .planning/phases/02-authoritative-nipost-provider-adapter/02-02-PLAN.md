# Phase 2 Plan 2: NipostProvider Implementation, Address Mapping, and Test Suite

**Plan:** `02-02`  
**Phase:** `02-authoritative-nipost-provider-adapter`  
**Target:** `packages/nipost`  
**Dependencies:** Plan `02-01`, `@ng-address/core`

---

## 1. Goal

Implement the `NipostProvider` class conforming to the `AddressProvider` contract (`lookupPostcode`, `reverseGeocode`, `search`, `healthCheck`), transform raw upstream responses into normalized `NigerianAddress` objects with `'nipost'` provenance, and provide comprehensive unit and integration tests.

---

## 2. Tasks

### Task 1: Payload Transformation & Normalization
- Create `packages/nipost/src/transformer.ts`:
  - Map raw NIPOST JSON response fields to `AddressComponents` and `NigerianAddress`.
  - Attach `FieldSource: 'nipost'` to all resolved fields (state, LGA, postcode, street, building, coordinates).
  - Use `@ng-address/core`'s state and LGA normalization to ensure canonical casing and codes.

### Task 2: Implement `NipostProvider`
- Create `packages/nipost/src/provider.ts`:
  - Implement `AddressProvider` interface.
  - `lookupPostcode(postcode: string, options?: ProviderRequestOptions): Promise<NigerianAddress | null>`:
    - Validate postcode format offline with `validatePostcode`.
    - Query NIPOST postcode endpoint.
    - Transform and return normalized address or return `null` if not found.
  - `reverseGeocode(coords: Coordinates, options?: ProviderRequestOptions): Promise<NigerianAddress | null>`:
    - Query NIPOST reverse geocoding endpoint.
    - Normalize returned components into `NigerianAddress`.
  - `search(query: string, options?: ProviderSearchOptions): Promise<NigerianAddress[]>`:
    - Query NIPOST address search endpoint with limit/offset.
    - Transform and return array of normalized addresses.
  - `healthCheck(): Promise<ProviderHealth>`:
    - Ping NIPOST status/health endpoint with latency tracking.
- Export everything from `packages/nipost/src/index.ts`.

### Task 3: Comprehensive Test Suite
- Create unit tests under `packages/nipost/test/`:
  - `client-guard.test.ts`: Test `ConfigurationError` when `window` object is mocked.
  - `http-client.test.ts`: Test retry backoff, jitter, timeout handling, status code mappings (401, 403, 429, 500, 503).
  - `provider.test.ts`: Test `lookupPostcode`, `reverseGeocode`, `search`, `healthCheck`, and normalization mapping with mock HTTP responses.
- Ensure 100% test pass rate across the monorepo (`pnpm test`).

---

## 3. Verification

- Run `pnpm test` (verify all core and nipost test suites pass).
- Run `pnpm build` across all monorepo packages.
