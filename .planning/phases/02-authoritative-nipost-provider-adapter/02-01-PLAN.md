# Phase 2 Plan 1: NIPOST Adapter Scaffolding & Resilient HTTP Client

**Plan:** `02-01`  
**Phase:** `02-authoritative-nipost-provider-adapter`  
**Target:** `packages/nipost`  
**Dependencies:** `@ng-address/core`

---

## 1. Goal

Scaffold the `@ng-address/nipost` package in the pnpm monorepo, define configuration schemas, and implement a resilient HTTP client with exponential backoff, jitter, rate limiting, and client-side isolation guards.

---

## 2. Tasks

### Task 1: Package Scaffolding & Monorepo Linkage
- Create `packages/nipost/package.json` with `@ng-address/core` workspace dependency, `tsup`, `vitest`, and `typescript`.
- Create `packages/nipost/tsconfig.json` extending root `tsconfig.base.json`.
- Create `packages/nipost/tsup.config.ts` for dual ESM/CJS and `.d.ts` builds.
- Configure scripts: `build`, `test`, `typecheck`, `clean`.

### Task 2: Configuration & Client-Side Safety Guard
- Define `NipostConfig` interface and Zod schema:
  - `apiKey`: required string.
  - `baseUrl`: optional string (default: official NIPOST endpoint).
  - `timeoutMs`: optional number (default: 5000).
  - `maxRetries`: optional number (default: 3).
  - `retryDelayMs`: optional number (default: 500).
  - `allowClientUsage`: optional boolean (default: false).
- Implement server-side runtime guard: check `typeof window !== 'undefined'` and throw `ConfigurationError` if `allowClientUsage` is false.

### Task 3: Resilient HTTP Transport Layer
- Create `packages/nipost/src/http-client.ts`:
  - Native `fetch` wrapper supporting AbortController timeouts.
  - Request headers (`Authorization: Bearer <apiKey>`, `Content-Type: application/json`, `User-Agent`).
  - Exponential backoff retry loop with random jitter for transient errors (network errors, 500, 502, 503, 504).
  - Status code mapping to `AddressError` subclasses (`ProviderError`, `ConfigurationError`).

---

## 3. Verification

- Run `pnpm install` across the monorepo.
- Run `pnpm --filter @ng-address/nipost build` to ensure clean build.
- Unit test HTTP client retry logic, error mapping, and client-side guard.
