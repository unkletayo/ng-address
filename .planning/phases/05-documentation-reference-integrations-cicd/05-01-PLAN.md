# Phase 5 Plan 1: Reference Applications (Next.js App Router & Express.js API)

**Plan:** `05-01`  
**Phase:** `05-documentation-reference-integrations-cicd`  
**Target:** `examples/nextjs-app-router`, `examples/express-api`  
**Requirements:** `DOCS-04`, `DOCS-05`  
**Dependencies:** `@ng-address/core`, `@ng-address/nipost`, `@ng-address/react`  
**Threat Ref:** `T-05-01` (Client-side secret leakage prevention via server-side proxy route)

---

## 1. Goal

Build two complete reference implementations demonstrating production patterns for Nigerian address workflows:
1. **Next.js 15 (App Router)** reference app demonstrating `<NigerianAddressInput />`, `<StateLgaSelect />`, and `<AddressConfirmationModal />` communicating with a secure server-side API proxy route (`/api/address/lookup`) that isolates `NIPOST_API_KEY`.
2. **Express.js API** reference service exposing REST endpoints (`/api/v1/address/normalize`, `/api/v1/address/validate`, `/api/v1/address/lookup`, `/api/v1/taxonomy/states`, `/api/v1/taxonomy/lgas`) with error handling, rate limit resilience, and typed responses.

---

## 2. Tasks

### Task 1: Express Backend Reference Application (`examples/express-api`)
- Create `examples/express-api/package.json` and `tsconfig.json`.
- Implement `examples/express-api/src/server.ts`:
  - `GET /api/v1/taxonomy/states` - Returns 36 states + FCT with geopolitical zone filtering.
  - `GET /api/v1/taxonomy/states/:state/lgas` - Returns official LGAs for state.
  - `POST /api/v1/address/normalize` - Normalizes incoming free-text or structured address.
  - `POST /api/v1/address/validate` - Validates syntax, state/LGA taxonomy, and postcode format.
  - `POST /api/v1/address/lookup` - Resolves NDAPS digital postcode with `NipostProvider`.
  - Structured error middleware mapping `AddressError` to clean HTTP responses (400, 404, 500).
- Add automated integration tests in `examples/express-api/test/api.test.ts`.

### Task 2: Next.js App Router Reference Application (`examples/nextjs-app-router`)
- Create `examples/nextjs-app-router/package.json` and configuration files.
- Implement server-side proxy API route:
  - `app/api/address/lookup/route.ts`:
    - Validates request body with `@ng-address/core`.
    - Resolves postcode using server-side `NipostProvider({ apiKey: process.env.NIPOST_API_KEY })`.
    - Returns serialized `NigerianAddress` with provenance metadata.
- Implement checkout / address capture page:
  - `app/page.tsx`:
    - Interactive address form using `@ng-address/react` components.
    - Integrated with `@ng-address/react/styles.css`.
    - Demonstrates confirmation modal and review workflow before submission.
