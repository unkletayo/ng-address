## 1. Goal

Author the comprehensive developer documentation suite (`Quickstart Guide`, `Security & Credentials Guide`, `Custom Provider Guide`, Root `README.md`, package-level READMEs) and configure automated GitHub Actions CI/CD pipelines enforcing type safety, linting, secret scanning, and multi-package test execution on Node.js 18.x and 22.x.

---

## 2. Tasks

### Task 1: Comprehensive Documentation Suite
- Create `docs/quickstart.md`:
  - 10-minute quickstart guide covering `@ng-address/core`, `@ng-address/nipost`, and `@ng-address/react`.
- Create `docs/security.md`:
  - Security architecture detailing server-side credential isolation, zero client-side secret exposure, sanitized error messaging, and data privacy principles.
- Create `docs/providers.md`:
  - Guide on implementing custom `AddressProvider` adapters (e.g. OpenStreetMap / Google Maps / proprietary databases).
- Create / update Root `README.md`:
  - Project banner, monorepo package breakdown, installation commands, architecture diagrams, and quickstart examples.
- Create package-level READMEs:
  - `packages/core/README.md`
  - `packages/nipost/README.md`
  - `packages/react/README.md`
  - `packages/cli/README.md`

### Task 2: GitHub Actions CI Pipeline
- Create `.github/workflows/ci.yml`:
  - Triggers on `push` and `pull_request` to `main`.
  - Node.js matrix: `[18.x, 22.x]`.
  - Steps: Checkout repository, setup pnpm, setup Node.js, install dependencies, typecheck (`pnpm typecheck`), build (`pnpm build`), and test (`pnpm test`).
