---

## 1. Goal

Implement all CLI subcommands for Nigerian address management: `lookup <postcode>` with `NipostProvider` integration, `validate <address>` for offline syntax/schema checks, `normalize <input>` with stdin piping support, `list-states` and `list-lgas <state>` for administrative browsing, and a guided interactive terminal wizard (`@clack/prompts`) when invoked without arguments in a TTY. Deliver a comprehensive test suite asserting command dispatch, flag parsing, exit codes, and output formatting.

---

## 2. Tasks

### Task 1: Lookup Command (`ng-address lookup <postcode>`)
- Create `packages/cli/src/commands/lookup.ts`:
  - Validates postcode format offline before network calls via `isValidPostcodeFormat()`.
  - Reads `NIPOST_API_KEY` from environment or `--api-key`.
  - If unauthenticated, displays informative instruction on how to acquire/configure `NIPOST_API_KEY` and exits with code `2`.
  - Instantiates `NipostProvider` and resolves postcode.
  - On success (exit `0`), prints formatted address card or JSON.
  - On error / not found, prints structured diagnostic and exits with code `1` or `2`.

### Task 2: Validate & Normalize Commands
- Create `packages/cli/src/commands/validate.ts`:
  - Validates raw address text or digital postcode format.
  - Provides detailed diagnostics (is recognized state, is valid LGA, is valid NDAPS postcode).
  - Exits with `0` if valid, `1` if invalid.
- Create `packages/cli/src/commands/normalize.ts`:
  - Accepts address string argument or reads from `stdin` stream (supports piped input).
  - Normalizes casing, trims whitespace, standardizes State and LGA names.
  - Outputs canonical string or full JSON representation (`--json`).

### Task 3: Administrative List Commands
- Create `packages/cli/src/commands/states.ts`:
  - Lists all 36 Nigerian states + FCT, capitals, and geopolitical zones.
  - Supports `--zone <zone>` filter.
- Create `packages/cli/src/commands/lgas.ts`:
  - Lists all official LGAs for a given state with alias matching.

### Task 4: Interactive Terminal Wizard
- Create `packages/cli/src/commands/wizard.ts`:
  - Interactive `@clack/prompts` wizard when `ng-address` is run with no arguments in a TTY:
    - Main menu: (1) Postcode Lookup, (2) Validate Address, (3) Normalize Address, (4) Browse States & LGAs.
    - Cascading prompts: State select -> LGA select -> summary card.

### Task 5: Integration & CLI Test Suite
- Create `packages/cli/test/lookup.test.ts`:
  - Test lookup with valid postcode and mocked provider.
  - Test lookup failure on invalid postcode format and missing API key.
- Create `packages/cli/test/validate.test.ts`:
  - Test valid vs invalid address strings and exit codes.
- Create `packages/cli/test/normalize.test.ts`:
  - Test normalization output and piped input simulation.
- Create `packages/cli/test/states.test.ts`:
  - Test state and LGA listing and filtering.
