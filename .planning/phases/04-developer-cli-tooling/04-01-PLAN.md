# Phase 4 Plan 1: CLI Package Scaffold, CAC Router, Environment Resolution & Formatters

**Plan:** `04-01`  
**Phase:** `04-developer-cli-tooling`  
**Target:** `packages/cli`  
**Requirements:** `CLI-04`  
**Dependencies:** `@ng-address/core`, `@ng-address/nipost`  
**Threat Ref:** `T-04-01` (Credential protection and sanitized error output)

---

## 1. Goal

Scaffold the `@ng-address/cli` package with TypeScript, binary distribution config (`"bin": { "ng-address": "./dist/bin.js" }`), and `tsup` executable bundling. Implement the core `cac` command router, environment variable resolution (`NIPOST_API_KEY`), standard exit code handlers (0, 1, 2), and output formatting engine supporting rich terminal cards (TTY), structured JSON (`--json`), and minimal script output (`--compact`, `--quiet`).

---

## 2. Tasks

### Task 1: Package Scaffolding & Build Pipeline
- Create `packages/cli/package.json`:
  - `name`: `@ng-address/cli`
  - `bin`: `{ "ng-address": "./dist/bin.js" }`
  - `dependencies`: `@ng-address/core: "workspace:*"`, `@ng-address/nipost: "workspace:*"`, `cac: "^6.7.14"`, `@clack/prompts: "^0.9.0"`, `picocolors: "^1.1.1"`
  - `devDependencies`: `tsup: "^8.4.0"`, `typescript: "^5.7.3"`, `vitest: "^3.0.7"`
- Create `packages/cli/tsconfig.json` extending root tsconfig.
- Create `packages/cli/tsup.config.ts`:
  - Entry: `src/bin.ts`
  - Format: `esm`
  - Clean output and inject `#!/usr/bin/env node` shebang banner.

### Task 2: Core CAC Router & Exit Handling
- Create `packages/cli/src/utils/exit.ts`:
  - Exit code constants (`SUCCESS = 0`, `VALIDATION_ERROR = 1`, `SYSTEM_ERROR = 2`).
  - Helper functions `exitSuccess()`, `exitValidationError(msg)`, `exitSystemError(err)`.
- Create `packages/cli/src/utils/env.ts`:
  - Resolves `NIPOST_API_KEY` from `process.env` or CLI `--api-key` flag.
  - Validates key format and guards against logging raw secrets.
- Create `packages/cli/src/cli.ts`:
  - Initializes `cac('ng-address')`.
  - Defines global flags: `--json`, `--compact`, `--quiet`, `--api-key <key>`, `--version`, `--help`.
- Create `packages/cli/src/bin.ts`:
  - Invokes `cli.parse()` with top-level error boundary capturing uncaught exceptions and mapping them to sanitized error messages.

### Task 3: Formatting & Output Engine
- Create `packages/cli/src/formatters/json.ts`:
  - Standard JSON output serializer with clean indentation or compact mode.
- Create `packages/cli/src/formatters/card.ts`:
  - Rich box layout for `NigerianAddress` displaying State, LGA, Ward, Street, NDAPS Postcode, coordinates, and provenance badges.
- Create `packages/cli/src/formatters/table.ts`:
  - Compact table formatter for listing states, capitals, zones, and LGAs.
- Create `packages/cli/src/utils/stdin.ts`:
  - Utility to read piped input from `process.stdin` when not attached to a TTY.

### Task 4: Unit Tests for Scaffold & Formatters
- Create `packages/cli/test/format.test.ts`:
  - Test JSON vs TTY card output formatting.
  - Test exit code utility mappings.
  - Test environment variable resolution and API key sanitization.
